IMAGES FOLDER — drop files in here, the site picks them up automatically.
No code changes needed. Just add a file with the exact name below and
refresh the page.

Required filenames (case-sensitive):

  dr-shehadeh.jpg
    Doctor's portrait, shown in the hero section's circular frame.
    Recommended: a square (or near-square) photo, at least 440x440px.
    Shows in a circle, so keep the subject centred.

  paediatric-encounter.jpg
    Cover of the book "Paediatric Encounter" (Book 1).
    Recommended: portrait orientation, around 500x700px (a 3:4.2 ratio).

  pediatric-cardiology.jpg
    Cover of the book "Pediatric Cardiology" (Book 2).
    Recommended: portrait orientation, around 500x700px (a 3:4.2 ratio).

Until a file is added, that spot shows a built-in placeholder (initials for
the portrait, a typeset title card for each book) so the site never looks
broken or unfinished.

Notes:
  - File extensions must be .jpg. If you only have a .png or .webp, either
    convert it to .jpg or ask for the src path in index.html to be updated
    to match your file's extension.
  - This folder is served at the site root as /images/... — do not rename
    the "images" folder or move it out of "public/".
